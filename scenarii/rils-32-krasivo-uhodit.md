# Рилс «Красиво уходит» (черновик)

> Нумерация Кати: кандидат. См. scenarii/README.md. Формат по разбору @natally_glow (`analiz/natally-glow-2026-11-15.md`): фраза поверх красивых кадров, без слов в кадре.

Статус (15.11): версия 1 `video/out/krasivo-v1.mp4` (13 с, без звука, композиция `KrasivoReel`, клипы готовит `video/tools/prepare_r32.py`), обложка `krasivo-oblozhka.jpg`. Без размытия (решение Кати 15.11). Проверка: идёт. Ждёт ответа Кати: кто мужчина в примерочной и согласен ли он. Даты и время публикации решает Катя.

## Сценарий (13 с)
1. 0-2,5 с: селфи в примерочной, купальник, поворот, замедление (видео Кати 15.11, 120 к/с). Текст: «Женщина, которая» / «ЗНАЕТ СЕБЕ ЦЕНУ,».
2. 2,5-4,5 с: походка мимо стойки, улыбка в камеру (ТЦ 14.11, плавное замедление). «НЕ СПОРИТ.»
3. 4,5-7 с: взгляд, разворот со взмахом волос.
4. 7-9 с: уходит. «Она просто».
5. 9-13 с: уходит, крупно со спины. «Она просто» / «КРАСИВО УХОДИТ.»
Текст: мелкая строка Inter, ключевые слова крупно Oswald, по центру ниже середины. Тёплая цветокоррекция, лёгкая виньетка, прямые склейки. Музыку Катя добавляет в Instagram.
