# video — сборка рилсов в Remotion

Установлено: remotion и @remotion/cli 4.0.538, react 19. Фото и видео в репозиторий не кладём (см. `.gitignore`).

Запуск (из папки `video/`): `npx remotion studio` для предпросмотра, `npx remotion render <композиция> out/reel.mp4` для рендера.
Браузер: в среде есть Chromium в `/opt/pw-browsers/chromium`; при рендере указать `--browser-executable=/opt/pw-browsers/chromium`, если Remotion не сможет скачать свой.
Композиций пока нет: рилс №2 собран Катей вручную.
